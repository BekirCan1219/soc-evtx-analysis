# SOC EVTX Analysis

Merhaba, SOC alanında kendimi geliştirmeye devam ediyorum. Bu repoda Windows olay günlükleri üzerine yaptığım analiz çalışmalarını paylaşıyorum.

## Amaç

Farklı log kayıtlarını inceleyerek olayları doğru okumayı, sıraya koymayı ve sade bir dille raporlamayı öğrenmek ve bunu pratiğe dökmek.

## İçerik

Her klasörde bir EVTX dosyası ve ona ait analiz raporu bulunuyor:

```text
Evtx01/
├── Evtx01.evtx
└── Evtx01 Analiz.docx
```

## Analiz Yöntemi

1. Logdaki olayları inceliyorum.
2. Önemli kayıtları ayırıp sıraya koyuyorum.
3. Ne olduğunu ve logların neyi göstermediğini raporluyorum.
4. Olayı tek cümleyle değerlendiriyorum.
